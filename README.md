# 8年级4班 · 体测备考管理工作台

一个**单文件网页工作台**，给广东省初中八年级体测备考期（2026-10-16 → 10-26，体测周至 10-30）的日常训练与记录用。

## 打开就用

线上地址：**https://sixhom.github.io/tice-workbench/**

也可以把 `index.html` 下载到本地**双击打开**——不用联网、不用安装、不用登录，离线照样用。

## 能干什么

| 板块 | 用途 |
| --- | --- |
| 📅 日程总览 | 11 天完整日历，点任意一天展开上午/下午两节课：热身 → 三组各自任务（组数·做法）→ 放松拉伸 → 安全提醒 |
| 🏃 每日执行 | 现场用：热身区｜分组任务区（男生/女生/体质薄弱三栏）｜放松区｜当日完成勾选 + 教师备注 |
| 👥 学生档案 | 47 人，姓名/性别/组别/各项成绩/伤病与特殊情况备注/出勤记录，表格里直接改 |
| 📈 成绩分析 | 对比历次模拟，高亮薄弱项、薄弱项目排行、每人进步幅度，自动匹配补强方案 |
| 📌 周末打卡 | 自动生成每周周末家庭作业，按三组分别输出，勾选登记 + 完成率，一键复制/导出清单发学生 |
| 🛡 安全预警 | 录哮喘、关节损伤等特殊情况，自动生成该生替代训练方案 |
| 📖 训练要点 | 7 大体测项目重难点与提升点、达标线速查、体测当天注意事项 |
| ⚙️ 备份打印 | 导出 CSV / JSON 备份、打印空白点名表、打卡清单、**全部训练日详案** |

## 分组规则

三个组别：**男生组（19）/ 女生组（15）/ 体质薄弱组（13）**。

体质薄弱组按**成绩底线**划分，不按主观印象：耐久跑慢于及格线（男 1000 米慢于 5′30″、女 800 米慢于 5′50″）或已申请免测待核的同学。补测完成后可在「学生档案」页随时调整组别。

训练安排遵守：体质薄弱组降负荷、先抓动作标准、不强行冲耐力；每节课必含热身与放松拉伸；耐力跑不连续两天高强度；按剩余天数自动切换基础期 → 强化期 → 模拟/减量期。

## ⚠️ 数据存在哪里

所有记录（成绩、点名、打卡、备注）保存在**本机浏览器的 localStorage**里（键名 `pe_tc_cal_v1`），不会上传到任何服务器。

- 换电脑、清缓存、换浏览器 → 已录数据会丢
- 请定期进「备份打印」页点 **下载备份**，存到 D 盘或网盘
- ⚠️ 线上版和本地文件是**两套数据**（浏览器同源隔离），两边各录各的，不会自动同步
