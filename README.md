# 8年级4班 · 体测冲刺工作台

一个**单文件网页工作台**，给广东省初中体测冲刺期（2026-10-16 → 10-30）的日常训练与记录用。

## 打开就用

线上地址：**https://sixhom.github.io/tice-workbench/**

也可以把 `index.html` 下载到本地**双击打开**——不用联网、不用安装、不用登录，离线照样用。

## 能干什么

| 模块 | 用途 |
| --- | --- |
| 今日作战 | 倒计时 + 当天上下午两节课详案，打开即用 |
| 全程计划 | 19 节课总表、两节课固定结构、目标设定 |
| 名单分组 | 47 人，按姓名/学号搜索、按组筛选、配速查询 |
| 点名记录 | 到/缺/病/事 四态，点一下记一个，自动统计 |
| 周末打卡 | 4 次打卡勾选，自动算完成率，可筛未交名单 |
| 成绩录入 | 摸底与实测分列，互不覆盖 |
| 补测待办 | 待核实事项逐项打钩 |
| 方案全文 | 11 章完整训练方案 |
| 现场速查 | 危险信号 / 场地检查 / 乳酸应对 |
| 备份打印 | 导出 CSV、导出 JSON 备份、打印空白记录表 |

## ⚠️ 数据存在哪里

所有记录（点名、打卡、成绩）保存在**本机浏览器的 localStorage**里，不会上传到任何服务器。

- 换电脑、清缓存、换浏览器 → 已录数据会丢
- 请定期进「备份打印」页点 **下载备份**，存到 D 盘或网盘

## 关于本仓库

部署形态为 GitHub Pages 静态站点，仅托管 `index.html` 一个文件，无后端、无外部依赖。
页面已加 `noindex` 标记，搜索引擎不会收录。
